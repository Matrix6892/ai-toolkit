# AI Toolkit · библиотека промптов и скиллов

Last reviewed: 2026-09-30.

Повторяемые способы работы с моделями: разработать полезный сценарий продукта, улучшить архитектуру, сохранить смысл разговора и вернуть выводы второго мнения. Начните с [каталога промптов](Prompts/Prompts.md) или [скиллов](Skills/Skills.md): выберите задачу и откройте соответствующий материал.

Репозиторий: [Matrix6892/ai-toolkit](https://github.com/Matrix6892/ai-toolkit). Библиотека самостоятельна: её можно читать на GitHub, клонировать на другую машину или открыть как обычную папку Markdown. Остальной Second Brain в этот репозиторий не входит.

## Устройство

- `Prompts/` — карточки рядом друг с другом. Группировка по задачам в каталоге; папки по моделям и версиям не нужны.
- `Prompts/Sources/` — точные исходники. Новая редакция карточки не меняет присланный оригинал.
- `AGENTS.md` — как агенту выбрать материал, обновить библиотеку и сохранить улучшение.
- `Skills/` — [каталог](Skills/Skills.md) и самостоятельные пакеты `Skills/<name>/SKILL.md`. Сейчас есть `product-engineering` с условными руководствами; автоматическая установка не выполняется.

Промпт вставляют в разговор. Скилл подключают к среде агента, когда задачу нужно выполнять по устойчивому процессу. Шаблон — заготовка результата, которую заполняют данными; отдельный раздел для шаблонов добавим только при реальной потребности.

## На другой машине

Нужны Git и GitHub CLI, авторизованный в аккаунте с доступом к этому приватному репозиторию. Сам вход в GitHub не сообщает агенту о существовании библиотеки: один раз дайте ему адрес и указатель ниже.

Первая загрузка:

```sh
mkdir -p "$HOME/.local/share"
gh repo clone Matrix6892/ai-toolkit "$HOME/.local/share/ai-toolkit"
```

Обновление существующей чистой копии:

```sh
git -C "$HOME/.local/share/ai-toolkit" pull --ff-only
```

`--ff-only` обновляет копию без автоматического создания слияния. Если есть локальные изменения, расходится история или недоступна сеть, агент сохраняет текущее состояние и сообщает ограничение. Изменения на других машинах не отправляются автоматически.

Добавьте в инструкции нужного агента этот короткий указатель; глобальные инструкции на других машинах репозиторий сам не изменяет:

```text
При разработке продукта, улучшении архитектуры, переносе контекста,
возврате второго мнения или поиске промпта/скилла используй Matrix6892/ai-toolkit.
Локальная копия: ~/.local/share/ai-toolkit; если её нет, получи через gh repo clone.
Перед использованием обнови чистую копию через git pull --ff-only.
Прочитай AGENTS.md, затем каталог и только подходящую карточку.
Если есть локальные изменения или нет доступа, сохрани их и назови ограничение.
Скилл устанавливай отдельно по правилам своей среды; чтение репозитория его не активирует.
```

У каждой карточки есть условия применения, входные данные, ожидаемый результат, механизм, готовый текст и сведения о проверке. Агент выбирает по задаче; он не загружает всю библиотеку в контекст.

## Как пополнять и проверять

Находку можно отправить в Inbox одной цитатой. Если известны источник, задача, модель и результат, добавьте их. Извлечение полезных промптов из сессий выполняется по выбранным сессиям или экспортам: сначала точные цитаты и признаки пользы, затем переработка и проверка.

Статусы различают уверенность: `draft` — предложенный текст; `user-reported` — пользователь сообщил о пользе; проверенный результат описывается конкретным сценарием и датой. Сохранение, красивый ответ и происхождение от ИИ сами по себе не доказывают эффективность.

## Версии и ведение

В обычном списке — одна текущая карточка. Git хранит старые редакции в скрытой `.git`; GitHub хранит удалённую копию истории. Номер вроде `v2` нужен при существенном изменении поведения или если уже дан автором; исправление опечатки нового номера не требует. Сжатый архив для этой текстовой коллекции не нужен.

Изменение готово, когда текст читается, локальные ссылки работают, исходник сохранён, результат проверки или её отсутствие отмечены и каталог актуален. При разрешённом ведении библиотеки агент фиксирует содержательное изменение коммитом и отправляет его в репозиторий; коммит описывает, что и зачем изменено. Один набор взаимосвязанных правок — один коммит.

## Возможное публичное использование

Репозиторий сейчас приватный. Новые материалы оформляются самостоятельно: без личных переписок, медицинских данных, секретов, абсолютных путей и зависимости от конкретной машины. Вместо полного чата сохраняйте переиспользуемый текст и обезличенное описание результата. Исходники и их происхождение сохраняются; лицензия приложенного v2 не установлена. Перед публичным выпуском нужно выбрать лицензию и проверить право распространять заимствованные материалы. Смена видимости — отдельное действие по прямому запросу владельца.
