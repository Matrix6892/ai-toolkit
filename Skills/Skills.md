# Скиллы

Last reviewed: 2026-10-14.

Скилл — повторяемая инструкция, которую агент читает под подходящую задачу. Например, при запуске продукта она помогает перевести идею в поведение, понятную часть реализации и доказательство результата. Само клонирование библиотеки не включает скилл в приложение.

При создании или обновлении пакета прочитайте [гайд по созданию скиллов](Создание%20скиллов.md): режим вызова обязательно задаётся явно в формате целевой среды.

## Выбор по задаче

| Задача | Пакет | Результат и статус |
|---|---|---|
| Неясное проявление, цель или существенный выбор решения | [Огранка проблемы и решения](ogranka/SKILL.md) | Наблюдаемый случай, приёмка, выбор и ограниченная проверка; draft; статическая проверка и ограниченная модельная проба 2026-10-14, общая эффективность не измерена |
| Уже разрешённое поручение с передачей замысла и сверкой границы | [Замысел и сверка с исполнителем](intent-based-delegation/SKILL.md) | Бриф, при необходимости сверка, приёмка артефактов; draft; статическая проверка и ограниченная модельная проба 2026-10-14, общая эффективность не измерена |
| Новый продукт или архитектурное изменение | [product-engineering](product-engineering/SKILL.md) | Сценарий, контракт, реализация и проверка; подробности ниже |

«Огранка» помогает прояснить проблему перед инженерной работой. `product-engineering` ведёт продуктовую и архитектурную реализацию; его ограниченное поручение можно уточнить через `intent-based-delegation`, если граница неясна или дорога. Это выбор по потребности, а не обязательная цепочка трёх пакетов. Для известной небольшой правки достаточно текущего процесса и прямой проверки.

## Разработка продукта

| Материал | Когда | Результат | Проверка |
|---|---|---|---|

## Использование на другой машине

Обновите локальную копию ai-toolkit по [README](../README.md). Попросите агента прочитать `Skills/product-engineering/SKILL.md`, применить его к задаче и читать только нужные ссылки. Для постоянного обнаружения установите всю папку `product-engineering`, включая `references/`, в поддерживаемое место скиллов вашей среды, сохранив существующие файлы. Здесь установка не выполнялась.

Пакет самостоятельный: внутренние ссылки остаются внутри папки скилла. Дополнительные инструменты, подписки или Scalens для использования не обязательны. Делегирование и запуск внешних систем выполняются только в рамках текущего поручения и правил среды.

Новые пакеты оформлены для Codex: в каждом `agents/openai.yaml` явно задано `policy.allow_implicit_invocation: true`. Для установки в Claude Code перенесите режим вызова по [существующему гайду форматов](Создание%20скиллов.md), не добавляя поле Claude в исходный Codex-пакет. Другой агент может читать пакет как инструкцию без установки. Runtime-ссылки новых пакетов остаются внутри пакета; записи о происхождении обозначают общую выборку, но не требуют её для работы.
