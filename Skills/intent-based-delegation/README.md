# Замысел и сверка с исполнителем: указатель совместимости

С 2026-10-14 инструкция перенесена в единый скилл [«Огранка»](../ogranka/SKILL.md), статус **draft**. Этот каталог — обычный Markdown-указатель, без `SKILL.md` и метаданных активного пакета.

Открой общий вход «Огранки»: он выберет [TO ORCHESTRATOR](../ogranka/references/to-orchestrator.md) для подготовки/уточнения поручения и приёмки либо [TO WORKER](../ogranka/references/to-worker.md) для изучения контекста, исполнения и возврата свидетельств. Обычно нужна только одна ветка; при запросе обоих текстов — две.

Полезные правила прежнего протокола и сведения о проверках сохранены в новом пакете. [Описание миграции и происхождение](../ogranka/references/source-and-changes.md) нужны только для сопровождения. Старые редакции файлов доступны в Git. Ранее установленные копии вне репозитория здесь не меняются.
