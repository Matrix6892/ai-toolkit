# Формы и конечные переходы

Заполняй только полезные поля; краткий режим может быть одним абзацем. Обязательные требования, доступные существенные данные, права и приёмку нельзя опускать ради краткости. Формы подходят и для кода, и для документов или исследовательского результата.

## Бриф координатора

```text
Сценарий и цель: …
Короткая исходная цитата (если нужна): …
Ожидаемый артефакт / полезный результат: …
Приёмка: критерий → наблюдаемый пример / способ проверки …
Одновременно ценные цели и их смысл (если есть): …
[Жёстко] Обязательные ограничения, включая технические: …
[Желательно] Предпочтения: …
[Неизвестно] Вопросы, меняющие выбор: …
Разрешённые действия / область файлов / вне рамок: …
Доступные данные, источники и ресурсы; способ доступа: …
Прошлые попытки и их фактический результат: …
Гипотеза способа (не требование, если это так): …
Режим: прямо к работе / анализ со сверкой …
Предел времени, стоимости, повторов; кому вернуть результат: …
```

Ссылка полезна только при доступе исполнителя. Если доступа нет, передай разрешённую выдержку или укажи пробел. Не объявляй заданный API гипотезой ради свободы метода.

## Сверка исполнителя после изучения контекста

```text
Я понимаю цель и границу так: …
Выведенный пример / контрпример и ожидаемый исход: …
Новые факты → свидетельства → влияние на решение: …
Ответы на неизвестное / оставшиеся неизвестности: …
Обоснованное расхождение с брифом (если есть): …
Действительные альтернативы (если нужны) и рекомендация: …
Существенный риск / слабое допущение / ограниченная проверка: …
Блокирующий вопрос или решение координатора (если нужно): …
Что можно продолжить независимо в рамках прав: …
```

Покажи существенные основания, а не скрытую цепочку рассуждений. Отсутствие нужного слова не доказывает непонимание: проверяется последствие на примере.

## Ответ координатора

```text
Понимание подтверждено / поправка на примере: …
Новые факты учтены; изменённые требования и основание: …
Ответы на блокирующие вопросы / что остаётся неизвестным: …
Гипотеза координатора как кандидат (если полезна): …
Разрешённая граница следующей фазы и приёмка: …
Переход: работа / одна уточняющая сверка / возврат владельцу цели …
```

Не требуй обязательного несогласия. Изменённые существенные критерии сообщай исполнителю до выполнения зависимой работы, не при финальной приёмке.

## Приёмка по артефактам

```text
Артефакты и доступ к ним: …
Критерий → выполнен / не выполнен / нельзя проверить → свидетельство: …
Фактически выполненные проверки и ограничения проверки: …
Существенные отклонения от брифа отдельно: …
Новые факты для координатора: …
Решение: принять / ограниченная доработка / нельзя проверить …
Следующее действие, владелец и предел: …
```

Координатор проверяет доступные артефакты по действительным критериям независимо от уверенности исполнителя. Недоступность артефакта или среды отмечается, а не заменяется предположением об успехе.

## Переходы и предел повторов

- Ясная обратимая задача: бриф → работа → приёмка.
- Неясная или дорогая граница: бриф → изучение → сверка → ответ → работа → приёмка.
- Задай конечный бюджет сверки по сложности и цене ошибки; обычно достаточно одного содержательного обмена. Дополнительное уточнение оправдано конкретным блокером, а не формальным повтором. При исчерпании бюджета верни нерешённую границу координатору с фактами и вариантом ограниченной пробы. Продолжай независимую разрешённую часть работы.
- Если нет двусторонних сообщений: изучение → законченный отчёт сверки координатору. Зависимая работа возобновляется отдельным поручением; независимая разрешённая работа может продолжаться.
- Приёмка с дефектом → ограниченная доработка → повторная проверка по конкретному дефекту. Число циклов выбирай по действующему бюджету и наблюдаемому прогрессу. Уже разрешённые исправления не требуют повторного подтверждения; при отсутствии нового сигнала или исчерпании бюджета верни конкретный блокер вместо бесконечного повтора.
- Успешная приёмка → завершение; недоступные доказательства → «нельзя проверить» с недостающим доступом. Конечный бюджет — редакторский предохранитель, не измеренная универсальная норма; действующие ограничения поручения имеют приоритет.
