# Fieldlight creative project showcase
Fieldlight runs a seasonal call for creative projects. The new workspace should replace forms, a review spreadsheet and hand-edited public pages.
A project can enter several tracks, such as Sound and Moving Image. Each track has its own reviewers and shortlist. The public site currently describes one project once, with its track results underneath.
We want to follow an entry from submission to published results without coordinators reconciling five tabs. Please explore a system direction; this is design work, not an implementation or infrastructure exercise.
There is an existing Rust application with a relational database. Rewriting it or changing storage is allowed if justified; headcount and familiarity with the stack are not constraints.
The next call opens in six weeks. A useful first slice matters more than a complete platform, but nobody has agreed what can be left manual.
