# Создание скиллов

Last reviewed: 2026-09-30.

## Обязательный выбор режима вызова

**`disable-model-invocation` обязательно писать явно в метаданных скилла для сред, которые поддерживают это поле.** Это правило нашей библиотеки, принятое владельцем 30 сентября 2026 года.

Метаданные — настройки перед основным текстом инструкции. Режим вызова определяет, может ли модель сама выбрать скилл по задаче. Например, справочник по архитектуре может подключаться автоматически, а скилл, который пользователь хочет запускать только вручную, — по явному вызову.

В `SKILL.md` для Claude Code поле находится на верхнем уровне YAML между `---`, рядом с `name` и `description`, а не внутри вложенного `metadata`:

```yaml
---
name: example-skill
description: Что делает скилл и когда его применять.
disable-model-invocation: false
---
```

- `false` — модель может выбрать скилл сама; явный вызов пользователем тоже доступен.
- `true` — автоматический выбор моделью отключён; скилл предназначен для явного вызова пользователем.

Обязательно наличие поля, а не значение `true`. Выбирайте значение по назначению скилла и поручению пользователя; при правке сохраняйте действующий режим, если его изменение не запрошено.

## Формат для Codex

В Codex режим задаётся в `agents/openai.yaml` через `policy.allow_implicit_invocation`. В наших Codex-пакетах эту настройку также указываем явно:

```yaml
policy:
  allow_implicit_invocation: true
```

Соответствие: `disable-model-invocation: false` → `allow_implicit_invocation: true`; `disable-model-invocation: true` → `allow_implicit_invocation: false`. Переносите смысл настройки в поддерживаемое поле целевой среды. Режим выбора скилла не даёт разрешений на внешние действия.

## Проверка при создании или обновлении

Проверьте целевую среду, явное булево значение режима (`true`/`false`, без кавычек), правильный файл и уровень вложенности. Сохраните остальные метаданные, проверьте YAML и доступность ссылок. Если меняется режим вызова, проверьте обнаружение скилла в целевой среде; правильный YAML сам по себе этого не доказывает.

## Источник

Обязательность явного поля — решение владельца библиотеки от 2026-09-30. Различие форматов Codex проверено по [официальной документации OpenAI](https://learn.chatgpt.com/docs/build-skills#optional-metadata) на ту же дату; там указано, что `allow_implicit_invocation: false` отключает неявный выбор, сохраняя явный `$skill`.
